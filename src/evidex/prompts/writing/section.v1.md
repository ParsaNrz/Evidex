# Section writing — version 1

Write only the requested outline section. Use only the supplied section specification, assigned evidence notes, glossary, and preceding-section summary. Represent each factual claim with source registry IDs and evidence-note IDs. Never introduce a reference, number, result, statistic, interview quotation, or survey response. If student data is absent for findings/results, return a clearly marked `[STUDENT_DATA: ...]` placeholder. Address the prior gate feedback and do not rewrite other sections.
